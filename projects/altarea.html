Altarea Website

Altarea develops shopping centers across France. They needed one website framework that could work for all of them, starting with Qwartz as the pilot, without becoming a generic template that erased each center's identity.

That was the real problem: each shopping center needed to feel distinct, with its own visual identity, while running on the same underlying structure. A single fixed design would either flatten every center into the same look, or force a new build for each one. Neither was sustainable.

The solution was to think of the whole site as a design system before that was the term I would have used for it. Every component was built to be adapted rather than duplicated: set a few parameters on a module and it could reconfigure itself into different layouts, list types and content structures across centers. I led art direction, interaction design and the initial UI design for the framework.

The hardest part wasn't technical, it was editorial: making a system flexible enough to hold real personality without ever feeling like a declined template.

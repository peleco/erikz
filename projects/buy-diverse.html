Buy Diverse

Buy Diverse is a platform dedicated to supporting minority-owned businesses: helping them market their products and services, get sales training, and connect with larger companies.

I started on art direction, creating the logo and the initial style guides to set a coherent visual language. From there I moved into UI design production, building out the screens and the component library the platform runs on.

Year

Agency

Role

The visual language was built around diversity and culture. The logo stands for inclusivity and unity, the color palette pulls from a range of cultures, and custom textures add depth that reflects the different backgrounds in the community.

In the UI production phase I built a component library as the base for the design system, set up the first style guide with clear design rules, and made the site fully responsive.
